Scenario walkthroughs

Four ready-made setups · App state: November 2026

Hold, don't tap. Main and music buttons: 1 second. Settings gear: 3 seconds. Let the thin bar fill completely.

1 · A standard work/earn day

Defaults — works with no setup at all.

  1. Open the timer: paused, both dials visible — Work (10:00) shows Ready, Earn (5:00) is dimmed at Waiting.
  2. Hold Start Work for 1 second — Running, dial fills, bottom line reads Work 10:00 · Earn 5:00 · Next up: Earn.
  3. Warnings arrive on their own at 1 minute and 30 seconds left (2 min optional), with a soft chime.
  4. At 0:00: Time's up + Work is finished! Earn is next. — and it waits. Hold Start Earn for 1 second.
  5. Earn ends with Earn is finished! Work is next. — hold Start again; Work → Earn all day. Skip → (hold 1 s) jumps ahead, Reset (hold 1 s) restarts the current block.

2 · Three work cycles before the earn

  1. Hold the gear ⚙ for 3 seconds → Timers → press + on Work cycles per earn until it reads 3 (1–10; default 1) → Done.
  2. Hold Start Work for 1 second. The Work card shows Cycle 1 of 3 with three pips (first bright, rest hollow); bottom line: Next up: Work cycle 2 of 3.
  3. Each ending announces the next: Work cycle 1 of 3 is finished! Work cycle 2 of 3 is next. — hold Start to continue; the badge advances and pips fill solid behind it.
  4. After the third: Work cycle 3 of 3 is finished! Earn is next., bottom line Next up: Earn. Hold Start Earn — the badge hides during Earn and the count restarts at 1 next round.
  5. Good to know: every work cycle gets its own full timer, warnings, chime and flash. Skip → advances the sequence · Reset zeroes the count · changing the setting restarts it.

3 · A calm sensory setup

  1. Hold the gear ⚙ for 3 seconds → Display → click a gentle theme (✓ marks the current): Calm (soft blue & green) is the default; Lavender, Mint or Peach are equally soft. Leave Large text / big display off unless needed.
  2. Media → Animation → a slow one: Drifting soft glow or Slow waves. Keep Animation reactivity at Gentle (default) or set Off — plain drifting for the calmest motion; lower Animation opacity (default 50%) if you want it barely there.
  3. Alerts → Sound → Single ping, Volume 30–40% (press Test to check). Keep Soft screen pulse when time is up off.
  4. Timers → keep Pause — wait for Start (default). If warnings feel like pressure, switch Show gentle warnings before time is up off — or tick only 1 minute left.
  5. Optional music: Media → Background music → pick a file, volume low — or the header music bar (⏮ ▶ ⏭, hold 1 s each). The built-ins are gentle and original; try Warm pad (slow strings).
  6. Done → hold Start Work for 1 second.

4 · A fully silent, visual-only classroom

  1. Hold the gear ⚙ for 3 seconds → Alerts → switch Sound alerts off (silences every warning and chime).
  2. Music off too: Music volume → 0, or hold the header ▶ 1 second (nothing to pause if no track was picked).
  3. Leave Soft screen pulse when time is up off for zero light changes — or on for one slow gentle fade at each end (never a hard blink).
  4. Timers → keep Show gentle warnings before time is up on: warnings still show as text (1 minute left, 30 seconds left) with sound off — quiet advance notice for the whole room.
  5. Keep Pause — wait for Start (default): the banner Work is finished! Earn is next. is the entire signal; anyone holds Start when ready.
  6. Display → consider Large text / big display so the time reads from the back of the room. The filling dials, status words (Running → Time's up) and the Cycle 2 of 3 badge carry every message — no sound needed. Hold Start Work to begin.
Why these work: hold to activate (no accidental triggers) · pause at the end (nobody is rushed) · soft optional cues (never a beep or hard flash) · settings remembered per machine so each room keeps its own setup. Staff who understand the why are less likely to override it — please pass that on.
